

# Projeto 2 — Controle Financeiro — Frontend

Interface em React para cadastro, login, lançamentos, categorias,
fontes e destinos, relatórios e previsão de faturas.

## Como rodar

1. Prepare o PostgreSQL e inicie a API seguindo o [README do backend](https://github.com/tkaoribruna/projeto2-fullstack-backend).
2. Abra outro CMD na raiz deste repositório e execute:

   ```cmd
   npm install
   npm run dev
   ```

3. Abra o endereço `Local` exibido pelo Vite, normalmente `http://localhost:5173`.

O frontend usa a API em `http://localhost:3000/api`.

## Conta de demonstração

Se você executou o `database/seed.sql` no banco usado pela API, entre com
`ana.demo@example.com` e a senha `Demo@12345`. Também é possível criar
uma conta pela tela de cadastro.
